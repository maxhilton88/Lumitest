💰 Currency System 2 currencies
🪙 Gold
Earnable
Earned through all activities. Buys consumables, common/rare items. The primary daily loop currency.
💎 Diamond
Premium
Earned via referrals & milestones only. Buys epic/legendary items and rare shop exclusives.
⭐ XP
Progress
Not a spendable currency — drives leveling. High XP = higher battle stats + better rewards per question.
❤️ HP
Resource
Depletes in battle. Restored via potions from shop. Gate for battle entry (≥10% max HP required).

Test & Practice — Session Reward Logic
How a session completes
Practice: Timer counts down. Kid must answer ≥ minQuestions before session ends. Timer hits 0 → unanswered questions counted as wrong. Session must complete fully to receive any reward.

Test: Kid must complete the entire test flow. Partial completion = no reward.

Both modes: XP always awarded on completion. Gold only awarded if accuracy ≥ 80%.

⬆️ Leveling & XP Curve Pokémon Medium Fast · Max Level 100
XP to reach level N = N³  ·  XP to next level = N³ – (N–1)³  ·  Max total XP = 1,000,000
Why level³?
Identical to Pokémon's "Medium Fast" growth curve. Early levels feel fast and rewarding. Mid-game slows naturally. Level 100 is a multi-year achievement — always something to work toward, never truly "done."
A child doing ~350 XP/day (study only, no battles): Level 20 in ~23 days · Level 30 in ~77 days
Premium battler (3 wins/day at Lv 30): ~750 XP/day → Level 30 in ~36 days

⚔️ Battle Damage Formula (Confirmed)
baseATK = 10 + (level × 3)
damage = (baseATK + equip_ATK) × age_scale × speed_bonus

⚡ Battle Economy
⚙️ Updated Stake Formula
calcBattleStake(levelA, levelB):
  avg = (levelA + levelB) / 2
  return min(150, max(10, round(avg × 5)))

Stake is based on the average of both players' levels. Hard ceiling of 150g kicks in at avg Level 30 — stays capped all the way to Level 100.
⭐ Battle XP Formula
avgLevel = (levelA + levelB) / 2
xpToNext = (avgLevel + 1)³ – avgLevel³
winXP = max(10, round(xpToNext × 0.05))
loseXP = 0  ·  forfeitXP = 0

Loser and forfeiter get 0 XP — prevents kids farming XP by deliberately losing to high-level players. Winner always gets at least 10 XP (floor).

🕸️ Spider Web — How it maps to rewards
Each skill has a Kod Kemahiran (e.g. MAT-T1-N01). Every activity (test/practice/flashcard/battle) is tagged to 1+ skill codes.

Mastery scoring per skill:
• 0 attempts → ◉ Unstarted
• 1–2 correct → ◉ Exploring
• 3+ correct, avg ≥60% → ◉ Learning
• 5+ correct, avg ≥80% → ◉ Proficient
• 10+ correct, avg ≥90% → ◉ Mastered

Parent spider chart shows mastery % per subject per year level. Weak nodes (Unstarted/Exploring) are surfaced in the daily quest recommendation engine — nudging kids to study gaps.
✅ Reward for mastering a skill node
When a skill goes from Learning → Proficient: +20 XP bonus + "Skill Unlocked" animation.
When a skill reaches Mastered: +50 XP + subject-specific badge (collectible) + gold bonus.
